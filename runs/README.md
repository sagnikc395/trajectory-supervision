# Run Ledger

Use this directory as the repo-backed ledger for agent-run experiments.

Rules:
- Put one Markdown note here per meaningful run.
- Keep large outputs in `artifacts/`.
- In each run note, record issue number, notebook, condition, seed, runtime, GPU, artifact paths, and any spec deviation.
- Mirror the same facts in the matching GitHub issue comment before closing the issue.
- Do not leave the only proof in chat logs, Colab tabs, or `~/Downloads`.
